Sonaroom
3D Acoustic Simulator

Model the room in 3D, see how long it rings in every octave band, place real acoustic panels, hear the room before and after, and check the prediction against a measurement from Sonasync.

Website: https://sonaroom.alphabellsystems.com/

Download
Get the latest version from the Releases page.

File	What it is
Sonaroom-<version>-windows-x64-setup.exe	Installer for Windows 10 / 11 (64-bit). No administrator rights needed.
Sonaroom-<version>-windows-x64.zip	The same program without installing: unzip and run Sonaroom.exe.
Linux packages (.deb, .rpm, .tar.gz) follow in a later beta.

Sonaroom is not code-signed yet, so Windows may show "Windows protected your PC" on first run. Click More info → Run anyway.

What it does
Build the room in 3D: a box or a custom shape, with a material on every surface
Reverberation per octave band: Sabine and Eyring (with air absorption), image sources and ray tracing
Acoustic treatment with real products: place panels on walls and ceiling and see the result
Auralization: listen to the room before and after treatment
Sonasync import: read a measured room impulse (EDT, T20, T30, C50, C80, D50 per band) and compare it with the prediction
Reports in PDF and HTML
Using it with Sonasync
Install both on the same computer. In Sonasync, export the room's impulse; in Sonaroom, open the Measurement panel and choose Import room impulse from Sonasync. The folder is found for you.
